## Бесплатный публичный запуск
Рекомендуемый вариант: GitHub Pages.
1. Создать публичный репозиторий `automarketuz-site`.
2. Загрузить `index.html`.
3. Settings → Pages → Deploy from branch → main / root.
4. GitHub выдаст бесплатный адрес `https://USERNAME.github.io/automarketuz-site/`.

Позже перед запуском проекта заменим на платный сервер и настоящий домен.
